## 管理台准入

- `/admin/*` 整体只允许已登录管理员访问，闸门挂在 `ent-auth`，与插件装载顺序无关；
  新增管理台路由时不会再因为各自忘记鉴权而留下匿名入口。
- 匿名只保留登录页自身的 `GET /admin` 与 `GET /admin/static/*`，两者均不包含业务数据。
- 普通用户仍可正常登录 DSH 客户端并访问自助用量，但无法读取或修改管理台数据、
  页面模块、插件开关、通知观测与协作诊断信息。
- 管理台登录显式携带 `scope=console`，非管理员得到可读的 `admin_only` 错误；
  密码校验仍先行，避免泄露账号角色信息。
- 修改用户角色会同步提升 `token_version`，原有 JWT 即时失效，降级后的管理员不能继续使用旧票。

## 模型元数据心跳热更新

- 网关 `modelFingerprint` 纳入 `contextWindow`、`maxTokens`、`inputModes`、`mode`、
  `thinking`、`defaultThinking` 与 `thinkingLevels`。
- 只修改已有模型的这些参数时，下一拍心跳即可产生新指纹，客户端自动执行
  `repairConfigure()` 重新拉取 `/v1/models` 并更新本地 Provider 配置。
- 模型增删、上下架、供应商启停、容灾和分组可见性变化的原有联动保持不变。
