# v3.2.0 · 客户端与环境物料全内网下发

装机不再依赖公网：网关把 DSH Desktop 安装包、Node LTS、pnpm 原生二进制都镜像到本地，
装机脚本只认网关下发的版本号与校验值 —— 脚本里不写死任何东西。

## 新增

- **桌面客户端镜像**（`src/core/desktop-repo.mjs`）：源 = GitHub Releases + ModelScope 镜像 +
  管理台手工上传；逐包校 sha256；保留窗口「已发布 + 最新 N 个」自动清理
- **环境物料镜像**（`src/core/env-repo.mjs`）：Node 走官方 `index.json` + `SHASUMS256.txt`
  （sha256）；pnpm 按平台镜像官方 `@pnpm/exe.<os>-<cpu>` 原生包并校 npm `dist.integrity`（sha512）
- **管理台「桌面客户端」四个二级页**：版本清单 / 环境物料 / 下发设置 / 离线上传；
  版本清单默认只列最近 3 个 + 已发布/本地已有的，可展开；同步状态、来源、字节数逐平台可见
- **装机脚本事实源**：`/setup/releases.json`（安装包）与 `/setup/env.json`（Node/pnpm）；
  `allowUpstreamFallback=false` 时脚本直接失败并提示让 IT 去同步，**不会偷偷出网**
- `npm run ui:check`：headless Chrome 逐条路由做全页面样式体检（揪「类名在 app.css 里
  根本没有样式来源」的元素）+ 截图落 `data/ui-shots/`
- `npm run test:mirror`：离线小 HTTP 源，7 步验证「下载 → 再同步跳过 → force 强拉 →
  校验值不一致重下」

## 变更

- 装机脚本 `[2/6]` 不再装 Homebrew：按官方 tarball 把 Node 装进 `~/.local/share`、
  pnpm 解包原生二进制到 `~/.local/bin`，**无 root、无交互、无 brew**；已装够用的
  （node >= 22.19 或 >= 24 / pnpm）一律沿用
- 同步跳过本地已有一致的实体（`force` 可强拉），自动补齐只在保留窗口内找缺口 ——
  不再出现「每个调度周期重拉几百 MB、下完又被 prune 删掉」
- 调度日志改为按真实包数计数，`入库 N 个包（另 M 个本地已有，未重复下载）`

## 修复

- **mac 装机脚本在「已装过旧版」的机器上必崩**：macOS 自带 bash 3.2 把紧跟变量的全角标点
  吞进变量名（`$TARGET_VER（` → 变量名多出 0xEF…），`set -u` 下当场
  `TARGET_VER?: unbound variable`，脚本停在 `[3/6]`。同类写法全脚本改为 `${VAR}`
- **Windows 装机脚本 `irm … | iex` 直接 ParserError**：PowerShell 5.1 的 `irm` 会把
  UTF-8 BOM 留在 `.Content` 字符串里，脚本首条语句被污染后 `param()` 不再被当成声明、
  整块逐行按语句执行（`InvalidLeftHandSide`，报在 `[string]$GatewayUrl` 那行）。
  改为手工绑 `$args` + 环境变量（`DSH_GATEWAY_URL` / `DSH_PLUGIN_VERSION` / `DSH_NPM_REGISTRY`），
  `-GatewayUrl` 传参照旧可用；服务端下发时再剥一次 BOM 兜底
- **管理台「保存成功」但什么都没改**：`api()` 把 opts 直接摊进 `fetch`，页面写
  `body: { v }` 发出去是 `"[object Object]"`，`readJson()` 解析失败当空体处理。
  现在 `api()` 兜底序列化普通对象，路由对坏 body 明确回 400，页面规则与 lint（R8）固化
- 「客户端管控」侧边栏二级项展开错位（分组头 append 次序反了）

## 兼容性与升级

- 无破坏性变更；数据目录新增 `data/desktop-repo/`、`data/env-repo/`（各含 `index.json` 与
  `files/`），老库无需迁移
- 纯内网启用步骤：管理台「桌面客户端 → 下发设置」把 Node/pnpm 打开并同步 → 「版本清单」
  发布目标版本 → 关闭公网回退 → 客户机执行
  `curl -fsSL http://<网关>:<端口>/setup/mac-setup.sh | bash`（Windows：
  `irm http://<网关>:<端口>/setup/windows-setup.ps1 | iex`）
- 补打了漏掉的 `v3.1.2` tag（当时只发了 npm 没打 tag，npm 与 git 已对不上）
