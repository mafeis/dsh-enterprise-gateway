## 本版本包含的提交（1 条）

- 3206a34 fix: 图片探针改以图内字符为主判据 — 只问颜色三成误判，"接受未确认"从此可复核

## 要点

- **判据换了**：16×16 纯色小图「问颜色」单次答错概率约三成（真机 22 次实测错 7 次，
  finish_reason 全是 stop、multimodal_tokens 明确返回 image:16），旧逻辑一次答错就把模型抖动
  写成能力结论。现改为 336×168 纯红底 + 黑色粗体 `K7XQ` 一图两用：背景色判「上游是否接受图片输入」，
  图内字符判「图是否真进了模型」——探针字符串不写进提示词，答对就不可能是猜的。
- **判定顺序**：读出字符 = real（决定性，happy path 只发 1 条请求）；只答对背景色 = 仍 real 但标注
  「OCR 未读出」；两项都没过才 accepted，并带上每轮原文；同一素材最多重测 3 次；
  `finish_reason=length` 不再白测第二轮；`multimodal_tokens` 作为客观旁证写进结论。
- **结构**：`sendParts` 拆成 `sendOnce`（传输层分类）+ `judgeAsk`（重测与投票），图片/视频共用；
  结果新增 `ocr/attempts/answer/finish`，`status/supported` 语义不变，`apply-probe` 写 `inputModes` 的规则一字未改。
- **UI**：模型目录新增「文字 ✓ K7XQ / 文字 △未读出」徽章，tooltip 带每轮原文与实测次数；
  旧 `lastProbe` 无 `ocr` 字段时自动不渲染，不影响历史数据。
